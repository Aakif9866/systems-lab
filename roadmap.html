~/roadmap

How it gets built

Foundation first, one system end-to-end, then the other nine on the proven path. Never all ten at once.

~/phases

Eight phases

  1. 01

    Foundation

    Monorepo, Next.js frontend, Rust control plane, Postgres, Docker-based local infrastructure.

  2. 02

    Execution framework

    Standard execution contract, event envelope, agent, logging, telemetry, lease + timeout cleanup.

  3. 03

    First system

    Distributed Database end-to-end: LSM engine, Raft, 5-node cluster, fault injection.

  4. 04

    Integrate

    All nine learning tabs wired to the real execution: overview → benchmarks.

  5. 05

    Validate

    Local execution, resource isolation, observability, first deployment.

  6. 06

    Remaining nine

    Allocator → VCS → Compiler → Query engine → Redis → Async runtime → Broker → Proxy → Container runtime.

  7. 07

    Deploy

    Frontend on Vercel, control plane + agents on Linux compute, managed Postgres.

  8. 08

    End-to-end

    Playwright journeys against the deployed platform for every system.

~/definition-of-done

A system counts as done when

  • □Builds and runs independently (cargo build -p / cmake --preset)
  • □Unit + integration tests pass in CI
  • □Benchmarks produce real numbers
  • □Architecture diagram references real files (checked in CI)
  • □≥ 3 guided experiments run against the real binary
  • □Events drive the visualizer
  • □Docs cover components, data flow, lifecycle, storage, concurrency, failure handling, interfaces
